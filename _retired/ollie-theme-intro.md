The free Ollie block theme is the foundation everything else builds on: a beautifully designed, blazing-fast WordPress theme made for the site editor. The docs in this section cover the theme itself — [what block themes are](/docs/theme/wordpress-block-theme/), [how Ollie is structured](/docs/theme/block-theme-structure/), and the design system behind it: [style variations](/docs/theme/style-variations/), [global styles](/docs/theme/global-styles/), and the [color palette](/docs/theme/ollie-color-palette/).

Running your own theme? See [Using Ollie Pro with a Custom Theme](/docs/theme/using-ollie-pro-with-a-custom-theme/).
