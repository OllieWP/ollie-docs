Menu Designer transforms WordPress navigation from plain text links into designed menus. Dropdowns and mega menus become block canvases — add images, buttons, multi-column layouts, feature callouts, anything — and mobile menus become fully designable too.

## Building a Dropdown or Mega Menu

Menus are designed as template parts in the Site Editor, so you build them with the same blocks and tools as everything else:

1. In your Navigation block, insert the **Dropdown Menu** block where you want the menu item.
2. Give it a label with the **Text** setting, then design the menu template it opens — a simple links list, a two-column layout with a featured image, or a full mega menu.
3. Shape the dropdown in the **Layout** panel: **Width** (content width, wide width, full width, or a custom pixel width), **Justification** (left, center, or right of the menu item), and **Top spacing** to control the gap below your header.

Other settings worth knowing: **Open on hover** (instead of click), and for mobile you can disable the dropdown entirely and send tappers to a **Fallback URL** instead — handy when a hover-driven mega menu doesn't translate to touch.

If you're running the Ollie theme, pre-designed menu templates give you a head start — pick one and customize rather than starting blank.

## Designing the Mobile Menu

Select your Navigation block and open the **Mobile Menu** panel. Choose (or create) a menu template to use as the mobile menu — meaning your mobile navigation can be a designed, full-featured layout instead of the default collapsed list. You can also:

- **Change mobile menu breakpoint** — set the screen width where the mobile menu takes over (default 600px).
- Style it in the Color panel: **Mobile menu background**, **Mobile toggle background**, and **Mobile toggle icon**.

## Good to Know

- Dropdowns position themselves intelligently near screen edges, and menus follow accessibility best practices for keyboard and screen reader users.
- Menu Designer is built on the modern WordPress Interactivity API and only loads its assets on pages that use it.
- Menu Designer is also available as a free standalone plugin on WordPress.org — your menus aren't locked to Ollie Pro.
