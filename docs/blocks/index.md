Ollie Pro includes custom blocks that extend what you can build with the WordPress editor — designed to feel completely native, with no shortcodes or page builders in sight.

**Carousel Designer** is the flagship: a block-native carousel suite for hero sliders, testimonials, logo marquees, and self-updating post carousels. Explore the docs in this section to get started, and check out the tutorials for step-by-step builds.
