<div class="wp-block-group alignwide is-style-default"><!-- wp:paragraph -->
<p>Ollie is a WordPress block theme that integrates seamlessly with all of the powerful new site building features like the site editor, patterns, global styles, and more. </p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>With Ollie, you can quickly and easily create beautiful, blazing-fast websites with the native WordPress site editor — no extra page builder or coding skills required.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"id":58417,"sizeSlug":"full","linkDestination":"none","className":"is-style-media-boxed"} -->
<figure class="wp-block-image size-full is-style-media-boxed"><img src="https://olliewp.com/wp-content/uploads/2024/06/ollie-docs-intro.webp" alt="Ollie Docs Intro" class="wp-image-58417"/></figure>
<!-- /wp:image -->

<!-- wp:paragraph -->
<p>Ollie is one of the most beautiful block themes out there, shipping with over 50 pixel-perfect patterns that you can use to quickly build out page sections or full page designs. Everything from headers, footers, sidebars, and content areas are fully customizable with a drag and drop interface.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Ollie is lightweight and blazing fast. Gone are the days of bloated WordPress websites that need a dozen plugins to look great and load fast. Ollie is fully-responsive out of the box and scores top marks across the board on performance tests.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Ollie is open source software, licensed under the&nbsp;<a href="https://www.gnu.org/licenses/gpl-3.0.html">GPL-3.0 license.</a></p>
<!-- /wp:paragraph -->

<h2 id="getting-started" class="wp-block-heading">Getting Started with Ollie</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>There are a few ways to install Ollie on your WordPress website. The easiest way is to install it from within your WordPress admin. Go to&nbsp;<strong>Appearance → Themes → Add New</strong>&nbsp;and search for Ollie, as demonstrated in the video below.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>You can also install Ollie manually by <a href="https://olliewp.com/download/" data-type="page" data-id="56999">downloading the theme</a> and uploading it to your WordPress site.</p>
<!-- /wp:paragraph -->

<!-- wp:video {"id":58424,"className":"is-style-media-boxed"} -->
<figure class="wp-block-video is-style-media-boxed"><video controls src="https://olliewp.com/wp-content/uploads/2024/06/docs-install-ollie.mp4"></video></figure>
<!-- /wp:video -->

<!-- wp:paragraph -->
<p>Once you have Ollie installed, all of the magic happens in the site editor, which you can get to by visiting <strong>Appearance → Editor</strong>. </p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>To learn more about working with block themes, visit the <a href="https://olliewp.com/docs/ollie-block-theme/wordpress-block-theme/" title="WordPress Block Themes">WordPress Block Themes doc</a> to read about the site editor, patterns, global styles, and more.</p>
